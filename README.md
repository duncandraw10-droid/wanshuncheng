# 萬順承實業網站

正式網站：https://wsctw.com/

Bootstrap 5、原生 JavaScript 與 Vite 靜態網站，沒有線上詢價收件後端。

## 開發與發佈

```sh
npm install
npm run dev
npm test
npm run build
```

`dist/` 為自動產生的發佈內容，不要直接修改。推送 `main` 後，GitHub Actions 執行測試、建置及 GitHub Pages 發佈。正式網域由 GitHub Pages 設定管理。

## 必須保留的行為

- 導覽順序：承製案例、設備能力、關於萬順承、製造能力、合作流程、聯絡詢價。
- Logo 使用現有資產；Topbar 與開場透過 CSS 呈現品牌藍，Footer 保留白色圖稿。
- 開場約 1.3 秒，回訪及深層連結略過；減少動態效果設定會停用開場與自動輪播。
- Hero 三張主視覺每 6.5 秒切換，主要詢價入口固定為 `#contact`；鍵盤焦點進入時暫停。桌機左右箭頭固定距視窗邊緣 24px，手機保留「查看承製案例」呼吸／浮動提示。
- 案例：桌機三張，平板約 1.2 張，手機一張且圖片維持正方形。每 4 秒自動前進，到最後一組回到開始；保留左右切換，滑鼠停留、鍵盤閱讀、展開介紹、圖片放大、離開區塊或切換分頁時停留。不顯示獨立的開始／暫停按鈕。
- 設備採 Bootstrap Tab／Pill，保留 250T、400T、500T 的圖片與介紹；手機才顯示圖片下方介紹。
- 三個公司數據為 35 年製程經驗、500T 最大設備與 50+ 累計合作客戶，以 Intersection Observer 觸發，1.8 秒遞增一次。
- 聯絡區保留三欄等寬等高、電話等距、按鈕群組置中與所有電話／Email 連結；「準備資料」桌機展開、手機可展開，項目間距分別為 8px／4px。
- 製造能力三項、品質管理四階段及合作流程四步，保留目前文案與響應式排列。品質段落使用與文案同色的實心方框。
- Footer 桌機導覽三欄兩列，左右間距 72px、上下間距 20px，整組靠右；手機維持雙欄排列。

## 追蹤與資料

GA4：`G-B4193HZQEP`。僅正式網域及原 GitHub Pages 網域會啟用設定與聯絡事件；本機測試不送出事件。聯絡事件為 `contact_click`、`contact_copy`、`inquiry_cta_click`，僅包含操作方法、位置與動作，不包含訪客聯絡資料或郵件內文。GA4 後台轉換設定需另外管理。

詢價透過 `tel:`、`mailto:` 或複製資料；目前沒有站內表單送出服務。請勿加入無法收件的送出按鈕或未確認的設備規格。

圖片更新請參閱 `IMAGE_REPLACEMENT.md`；視覺規範請參閱 `DESIGN.md`。

## 服務與案例子頁

四頁主文均為靜態 HTML，建置時即完整輸出，不依賴瀏覽器載入才出現。每頁有獨立 Title、Description、Canonical、OG 分享設定、企業與麵包屑結構化資料；服務頁另有 Service 資料。FAQ 使用原生 details／summary，支援鍵盤與無 JavaScript 閱讀。

子頁中的 `<!-- shared:header -->` 與 `<!-- shared:footer -->` 由 Vite 在資產處理前展開，來源為 `index.html` 的同名元素，因此修改全站導覽、Logo 或 Footer 資料時只需修改首頁。子頁的首頁區塊連結導回首頁；詢價按鈕則前往當頁電話／Email 區。子頁不播放開場動畫，也不啟動首頁輪播。

新增頁面時，須同時加入 Vite 多頁入口、sitemap 與連結檢查。案例只使用既有產品照片與已確認資訊；產品名稱不代表公開特定測試等級或認證。

## 服務頁製程與評估插畫

- SMC／BMC 服務頁開頭介紹後加入四步製程，固化歸於加熱加壓步驟，之後開模取件與修整。模具移轉頁在既有四步驟之前加入設備／模具關係示意與四項評估說明。
- `public/images/diagrams/` 保存五張上線用 SVG 剖面圖；執行 `node scripts/generate-molding-diagrams.mjs` 可從共用輪廓重新產生。標題、步驟與解說是可閱讀的 HTML；圖片提供 alt、尺寸與延遲載入，向量圖不需要多份解析度版本。
- 二維剖面使用無單位示意座標，未加入設備尺寸、溫度、壓力或性能數據。閉模時外側分模面接觸，材料位於上下模之間；開模、取件沿用同一模具輪廓。導向位置一致，壓板與模具貼合，固定件及頂出細節省略並註明。
- 先前影像生成稿與檢查紀錄保存在工作輸出資料夾；已取代的光柵圖不再隨網站發布。這些圖不代表實際設備、安裝方式或適配保證。
